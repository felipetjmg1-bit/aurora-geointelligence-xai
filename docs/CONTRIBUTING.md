# Contributing / Como contribuir

## Português

Contribuições são bem-vindas para esta iniciativa experimental. Abra uma issue com problema reproduzível, entrada sintética ou aberta, comportamento esperado e versão do ambiente. Não anexe cenas restritas, dados pessoais ou segredos. Em pull requests, inclua testes, atualize documentação e descreva como reproduzir alterações. Não rotule grupos de cores como categorias sem dados e protocolo de validação adequados.

Execução local: `python -m venv .venv`, ativar o ambiente, `pip install -r requirements.txt`, `python app.py`; testes: `pytest -q`. Antes de propor nova integração externa, cite documentação primária, termos de licença e autorização aplicável. Não use marca STAR.VISION para sugerir endosso.

## English

Contributions are welcome to this experimental initiative. Open an issue with a reproducible problem, synthetic/open input, expected behavior and environment version. Do not attach restricted scenes, personal data or secrets. Pull requests should add tests, update documentation and describe how to reproduce changes. Do not label color clusters as thematic categories without suitable data and validation protocol.

Local run: `python -m venv .venv`, activate the environment, `pip install -r requirements.txt`, `python app.py`; tests: `pytest -q`. Cite primary documentation, license terms and applicable authorization before proposing external integrations. Do not use the STAR.VISION mark to suggest endorsement.
