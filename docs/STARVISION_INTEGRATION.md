# STARVISION DATA CONNECTOR / Conector STAR.VISION

## Português

O conector STARVISION DATA CONNECTOR é, nesta versão, apenas um ponto de extensão documental: **nenhuma conexão, API, endpoint, autenticação, download ou dado STAR.VISION foi implementado ou testado**. O MVP aceita importação manual de arquivos locais autorizados, sem relação automática com o programa STAR.VISION — Oriental Smart Eye (OSE), categoria Orange.

Antes de qualquer integração futura, confirmar com documentação oficial e autorização aplicável os métodos de aquisição e exportação, licenças de dados, termos do programa, autenticação permitida, sensor, resolução, bandas, unidades, CRS, metadados e restrições de redistribuição. Não contornar autenticação nem inventar endpoints, credenciais ou capacidades. Registrar no conector, por cena, fonte, licença, sistema de coordenadas, resolução medida, bandas e limitações. A resolução de 0,5 m só poderá ser reportada se os metadados válidos do arquivo a confirmarem.

A referência ao programa OSE decorre da descrição fornecida pelo fundador como acesso a recursos. Ela não implica parceria comercial, patrocínio, certificação, endosso ou desenvolvimento conjunto.

## English

In this version, STARVISION DATA CONNECTOR is only a documented extension point: **no STAR.VISION connection, API, endpoint, authentication, download or data has been implemented or tested**. The MVP supports manual import of locally authorized files, with no automatic link to the STAR.VISION — Oriental Smart Eye (OSE), Orange-category program.

Before any future integration, verify through official documentation and applicable authorization the acquisition/export methods, data licenses, program terms, permitted authentication, sensor, resolution, bands, units, CRS, metadata and redistribution restrictions. Do not bypass authentication or invent endpoints, credentials or capabilities. Record each scene's source, license, coordinate system, measured resolution, bands and limitations. A 0.5 m resolution may only be reported when valid file metadata confirms it.

The OSE program reference is based on the founder's description of access to resources. It does not imply a commercial partnership, sponsorship, certification, endorsement or joint development.
